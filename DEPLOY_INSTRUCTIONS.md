## 📋 Step-by-Step Deployment (5 Minutes)

### **STEP 1: Merge the Pull Request** (2 minutes)

1. **Open this URL in your browser:**
   ```
   https://github.com/mohdmansoorak/Health-App/compare/claude/health-insurance-app-01EvFJqrr14p9P9kLb5fxmVD
   ```

2. **You'll see a page that says "Comparing changes"**
   - You should see commits like:
     - "Add docs folder with production build for GitHub Pages deployment"
     - "Fix GitHub Pages routing for React app"
     - "Merge Flutter mobile app and deployment automation"

3. **Click the green button that says "Create pull request"**

4. **On the next page:**
   - Title will be auto-filled
   - Click the green "Create pull request" button again

5. **Finally, click "Merge pull request"**
   - Then click "Confirm merge"
   - You'll see: "Pull request successfully merged and closed"

---

### **STEP 2: Configure GitHub Pages** (2 minutes)

1. **Open GitHub Pages settings:**
   ```
   https://github.com/mohdmansoorak/Health-App/settings/pages
   ```

2. **Under "Build and deployment" section:**

   **Find "Source" dropdown:**
   - Click on it
   - Select: **"Deploy from a branch"**

3. **Under "Branch" section:**

   **First dropdown (Branch):**
   - Click on it
   - Select: **"main"**

   **Second dropdown (Folder):**
   - Click on it
   - Select: **"/docs"**

4. **Click the "Save" button**

5. **Wait for confirmation:**
   - You'll see: "Your site is ready to be published at..."
   - After 1-2 minutes, refresh the page
   - It will change to: "Your site is live at..."

## 🔍 Troubleshooting

### If the page shows "404 Not Found":
1. Check that you selected "/docs" folder (not "/root")
2. Wait 2-3 minutes after saving settings
3. Clear your browser cache (Ctrl+Shift+R or Cmd+Shift+R)

### If you see old/blank page:
1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
2. Try incognito/private browsing mode
3. Check GitHub Pages settings show "Your site is live"

### If settings page doesn't show /docs option:
1. Make sure the PR is merged first
2. Refresh the settings page
3. The /docs folder should appear in the dropdown
