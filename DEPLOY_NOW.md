## 📱 4 STEPS TO GET YOUR APP ON IPHONE (10 Minutes)

### STEP 1: Enable GitHub Pages (1 minute)

1. Click this link: https://github.com/mohdmansoorak/Health-App/settings/pages

2. You'll see a page titled "Pages"

3. Under "Build and deployment", find the **"Source"** dropdown

4. Click the dropdown and select **"GitHub Actions"**
   - NOT "Deploy from a branch"
   - Choose the one that says "GitHub Actions"

5. The page will automatically save

✅ Done! GitHub Pages is now enabled.

---

### STEP 2: Run the Deployment (2 minutes)

1. Click this link: https://github.com/mohdmansoorak/Health-App/actions

2. On the left sidebar, click **"Build and Deploy Web App"**

3. You'll see a blue button that says **"Run workflow"** - Click it

4. A small popup appears:
   - **Branch**: Select `claude/health-insurance-app-01EvFJqrr14p9P9kLb5fxmVD`
   - Click the green **"Run workflow"** button

5. Wait a few seconds - you'll see a new workflow appear with a yellow circle (running)

✅ Done! Deployment started.

---

### STEP 3: Wait for Build to Complete (5-7 minutes)

1. Stay on the Actions page

2. Watch your workflow (has a yellow/orange circle)

3. When it turns to a **green checkmark ✓**, deployment is complete!

4. If it shows a red X, click on it to see the error (unlikely with our fixes)

✅ Done! App is deployed and live!

---

### STEP 4: Install on Your iPhone (2 minutes)

1. **On your iPhone**, open **Safari** (must be Safari, not Chrome!)

2. Go to this URL:
   ```
   https://mohdmansoorak.github.io/Health-App/
   ```

3. Your app loads! (may take a few seconds first time)

4. Tap the **Share button** (square with arrow pointing up) at the bottom

5. Scroll down and tap **"Add to Home Screen"**

6. You'll see:
   - App icon preview
   - Name: "Health Insurance"

7. Tap **"Add"** in the top right corner

8. Go to your iPhone home screen

9. You'll see the **Health Insurance app icon**!

10. Tap it - it opens full screen like a native app!

✅ Done! App installed on iPhone!

## 🐛 If Something Goes Wrong

### Workflow Failed (Red X):
1. Click on the failed run
2. Click on the failed job
3. Read the error message
4. Usually it's a syntax error in code
5. Fix and push again

### Can't Find "Run workflow" Button:
- Make sure you're on the Actions tab
- Click "Build and Deploy Web App" on the left
- Button appears on the right side

### 404 Error When Opening URL:
- Wait 10 minutes - deployment might still be processing
- Check workflow has green checkmark
- Check GitHub Pages is enabled (Step 1)

### "Add to Home Screen" Not Showing on iPhone:
- MUST use Safari browser (not Chrome)
- Tap Share button (box with arrow)
- Scroll down in the share sheet
